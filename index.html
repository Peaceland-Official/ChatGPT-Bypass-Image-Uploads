1. Connect image storage

This static website uses Cloudinary to store photos. You'll need a free Cloudinary account and an unsigned upload preset. You only need to configure this once on this device.

Setup: Create a free Cloudinary account → copy your Cloud name from the dashboard → Settings → Upload → Upload presets → Add upload preset → set Signing mode: Unsigned → save and copy its name. If available, restrict the preset to images and set file-size limits. Never put your API secret here. Cloudinary may change the exact menu names.

Cloud name and preset are saved only in this browser. Uploaded files are hosted externally and are not password-protected. Anyone with the image URL can view it.
